Cara pakai

terminalsh
# rotating — tiap koneksi IP baru
curl -x http://budi:RAHASIA@gw.dgiproxy:8899 https://api.ipify.org

# sticky — satu IP dikunci selama kerja
curl -x http://budi-sabc123:RAHASIA@gw.dgiproxy:8899 https://api.ipify.org

# filter negara keluar
curl --proxy socks5h://budi-cUS:RAHASIA@gw.dgiproxy:8899 https://api.ipify.org

Sticky session

Tambah -s<token> di username. IP sama selama sesi, ganti tinggal ganti token.

Filter negara

Tambah -c<CC>. Keluar dari negara yang diminta langsung lewat direktif.

HTTP + SOCKS5

Satu port dua protokol, dideteksi otomatis.

Kuota dua arah

Habis kuota, akses berhenti sendiri — 402, bukan tagihan kejutan.
